# cursor-personal-skills

开源的 Cursor Agent Skills 集合。每个 skill 是独立目录，可按需安装，与具体业务仓库无关。

## 已收录

| Skill | 说明 |
|-------|------|
| work-daily-report | 中文个人工作日报：从 Git 与对话存档整理实事，面向领导汇报 |

## 安装

```bash
npx skills add beishimvp-pixel/cursor-personal-skills --skill work-daily-report
```

或手动复制 `work-daily-report` 目录到：

`%USERPROFILE%\.cursor\skills\work-daily-report\`

## 仓库说明

- 本仓库只放可公开复用的 Agent Skills，不含密钥、账号或私有业务代码。
- Skill 以目录为单位维护；新增 skill 时增加同级目录并更新本表即可。
- 欢迎按需 fork / 安装；使用方式遵循各 skill 目录内的 `SKILL.md`。
