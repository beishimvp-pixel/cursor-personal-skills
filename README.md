# cursor-personal-skills

个人 Cursor Agent Skills 仓库。

## 已收录

| Skill | 说明 |
|-------|------|
| work-daily-report | 中文个人工作日报，面向领导汇报 |

## 安装

```bash
npx skills add beishimvp-pixel/cursor-personal-skills --skill work-daily-report
```

或手动复制 `work-daily-report` 目录到本机：

`%USERPROFILE%\.cursor\skills\work-daily-report\`

## 说明

- 本仓库与业务项目 DELIN-SZDP 分开维护
- Skill 供个人/团队 Agent 使用，不含业务密钥
